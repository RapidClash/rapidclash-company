# RapidClash

The repository contains documentation as a code framework to describe how
the organization operates — platform code plus docs-as-code (architecture,
processes, interfaces, AI assistant instructions), reviewed through pull
requests like any other change.

- Engineering and process documentation: [`docs/`](docs/README.md) — start there.
- Governance, legal, corporate, policies and audit evidence: Google Drive
  (RapidClash Workspace) — restricted areas, not duplicated here.
- Task tracking, roadmap, MVP checklist, decision log, document register:
  the "RapidClash Launch Roadmap 2027" Google Sheet.
- Open operational issues (access, tooling, pending decisions): [`ISSUES.md`](ISSUES.md)
  — not GitHub Issues; a plain-text log any human or AI assistant with repo
  access can read and update. Closed issues move to [`ISSUES_HISTORY.md`](ISSUES_HISTORY.md).

Platform code lives alongside `docs/` as it's added; see
[`docs/adr/0001-platform-baseline.md`](docs/adr/0001-platform-baseline.md)
for the architecture this repo is built toward.

This repository is RC-07-003's deliverable (artefact ID, see the document
register). Origin: the RapidClash MVP Collaboration Framework, 2026-10-27.
